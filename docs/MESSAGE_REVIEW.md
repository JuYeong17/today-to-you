# 200개 문구 재검토

이 문서는 앞선 편집 기록이다. 후속 변경은 [최종 검수 기록](MESSAGE_FINAL_REVIEW.md)을 참고한다.

2026-11-06. 외부 자료나 API를 사용하지 않고 전체 문구를 편집 검토했다.

## 기준

친구에게 카톡으로 보낼 수 있는지, 뜻이 바로 이해되는지, 억지로 창의적으로 보이려는 표현은 없는지 각 문장을 확인했다. 자연스러운 기존 문구는 유지했다. 자동 검사는 길이와 형식만 확인하며 재미와 자연스러움을 보증하지 않는다.

- FORTUNE: 추상적인 풍경·취향 대신 할인, 자리, 음식, 일정 등 구체적인 작은 행운으로 수정했다. 미래를 보장하지 않는다.
- COMFORT: 문학적인 감정 표현을 줄이고 일상적인 공감으로 바꿨다.
- REAL_TALK: 물 마시기·정리하기 같은 생활지도 대신 과한 계획, 비교, 부담 등을 친구 말투로 짚었다. SAD·TIRED에서는 비난과 재촉을 피했다.
- HUMOR: 억지 비유와 사물 의인화를 없애고 배달, 사진, 반려동물 영상, 약속 준비 등의 상황으로 바꿨다. 기분이나 개인 특성을 조롱하지 않는다.

## 저장된 결과에 미치는 영향

현재 저장 검증은 문구가 카탈로그에 있는지 확인한다. 이번에 교체된 문구가 이미 저장되어 있으면 다음 복원 시 무효가 되어 같은 날에도 새 문구를 뽑을 수 있다. 유지한 문구의 저장 결과는 그대로 복원된다. 이번 작업에서 저장 로직은 변경하지 않았다.
