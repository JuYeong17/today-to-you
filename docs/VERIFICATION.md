# 출시 전 검증 기록

2026-11-06. 로컬 정적 빌드와 Codex 내장 브라우저에서 확인했다. 외부 사이트 조회·패키지 다운로드·배포는 수행하지 않았다.

## 발견 및 수정

**문제:** localStorage와 Web Locks 요청이 모두 차단되는 환경에서, 저장 불가 안내는 표시되지만 뽑기가 오류로 끝났다.

**수정:** `src/lib/browser-lock.ts`에서 잠금 획득 자체가 거부되면 현재 탭의 선택·메모리 유지로 진행하도록 했다. 잠금을 획득한 뒤 문구 선택 작업 자체가 실패하면 작업을 재실행하지 않는다. 정상 Web Locks 환경의 탭 간 직렬화는 유지한다.

수정 전 실제 화면의 실패 안내를 재현했고, 수정 후 차단 상태에서 결과와 저장 불가 안내가 함께 표시되는 것을 확인했다. 관련 회귀 테스트 2개를 추가했다.

## 남은 확인과 알려진 한계

- 실제 휴대폰 Safari·Chrome과 실제 Vercel 주소에서의 확인은 배포 후 수행한다.
- 내장 브라우저의 모바일 크기로 확인한 결과를 실기기 검증으로 간주하지 않는다.
- Web Locks가 없거나 차단된 경우 서로 다른 탭의 완전 동시 뽑기는 단일 결과를 보장하지 못한다. 같은 탭의 중복 방지는 유지한다.
- 저장소가 막혀 있으면 현재 탭까지만 결과를 유지하며 새로고침·다른 탭의 결과 공유는 보장하지 않는다.
- 현재 저장 검증은 카탈로그에 있는 문구만 인정하므로 삭제·교체된 문구는 같은 날에도 재선택이 가능하다.
