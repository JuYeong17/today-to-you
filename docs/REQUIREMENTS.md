# 요구사항 — 오늘, 너에게

슬로건: **너에게 건네는 한마디** · 영문명: **Today, To You**

## 목적과 MVP

로그인 없이 기분과 유형을 고르고, 사전 작성 문구로 작은 위로와 재미를 얻는다. Gemini 생성 요구사항은 1차 MVP에서 제외한다.

- 기분: HAPPY 행복, NORMAL 평범, TIRED 지침, SAD 우울, EXCITED 설렘. 기본값 NORMAL이며 선택사항이다.
- 유형: FORTUNE 오늘의 운세, COMFORT 오늘의 위로, REAL_TALK 오늘의 팩폭, HUMOR 오늘의 웃음. 기본값 COMFORT다.
- 조합별 10개, 총 200개 문구 중 선택한 조합에서 균등 무작위 선택한다.
- 문구는 자연스러운 한국어 한 문장, 공백 포함 45자 이내, 친근한 반말이다.
- 친구가 카톡으로 보낼 법한 말로 쓰고, 즉시 이해되지 않는 비유·의인화·억지 말장난은 제외한다.
- 운세는 구체적인 일상의 작은 행운, 위로는 가벼운 공감, 팩폭은 잔소리 없는 현실적인 말, 웃음은 공감되는 일상 상황으로 구성한다.
- 같은 종결 구조를 반복하지 않으며 SAD·TIRED에서는 감정을 놀리거나 행동을 재촉하지 않는다.
- 감정 부정·비하·공격·불안 유발·부정적 운세·미래 단정을 제외한다.
- 한국 시간 자정 기준 하루 한 번 뽑고 localStorage에 날짜, 기분, 유형, 문구를 저장한다.
- 같은 날 방문하면 선택 화면 대신 저장된 결과를 보여준다.
- 열린 탭에서도 자정이 지나면 다시 선택할 수 있다. 백그라운드 탭은 복귀 시 확인한다.
- 결과에는 날짜, 선택값, 문구, 복사 버튼과 다음 이용 안내를 제공한다.

## 흐름

방문 → 저장값 확인 → 오늘 결과가 있으면 결과 표시 → 없으면 기분·유형 선택 → 문구 뽑기 → 저장 → 결과 → 복사.

기분·유형을 변경해도 같은 날 저장된 문구를 다시 뽑지 않는다. 중복 클릭을 차단한다. Web Locks를 사용할 수 있으면 탭 간 뽑기도 순서대로 처리한다. API가 없거나 접근이 차단되어도 현재 탭에서 뽑기는 가능해야 한다.

## 예외와 비기능 요구사항

- 손상된 JSON, 잘못된 버전·타입·문구는 폐기하고 복구한다.
- 저장소 접근 또는 쓰기가 불가능하면 해당 탭 메모리에 결과를 유지하고 재방문 보장이 안 된다는 안내를 표시한다.
- 복사 권한이 없거나 Clipboard API를 지원하지 않으면 문구 선택으로 복사하도록 안내한다.
- 제한은 브라우저 저장소 기반 UX다. 데이터 삭제, 다른 브라우저, 시스템 시계 변경을 방지하지 않는다.
- Web Locks 미지원 또는 접근 차단 환경에서는 동시에 뽑는 서로 다른 탭의 충돌을 완전히 방지하지 못한다.
- 모바일 우선, 라디오 그룹, 키보드 초점, 상태 알림, 모션 감소를 지원한다.
- 코랄·크림·뉴트럴 색상과 CSS 토큰을 사용한다.
- 외부 폰트·분석 스크립트 없이 정적 콘텐츠로 동작한다.

## 제외 기능

백엔드 API, Gemini 호출, API 키, DB, 계정, 광고, 친구에게 보내기, 서버에서의 하루 제한은 구현하지 않는다.
