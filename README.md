# 오늘, 너에게

**너에게 건네는 한마디** · Today, To You

오늘 기분은 어떤가요? 듣고 싶은 말을 고르면, 지금 기분에 어울리는 짧은 한마디를 전해드려요.

로그인 없이 하루에 한 번, 가볍게 위로받거나 피식 웃을 수 있는 모바일 웹서비스입니다.

## 주요 기능

- **기분 선택** — 행복, 평범, 지침, 우울, 설렘 중 오늘의 기분을 골라요.
- **메시지 선택** — 운세, 위로, 팩폭, 웃음 중 듣고 싶은 말을 골라요.
- **오늘의 한마디** — 기분과 유형에 맞춰 준비된 200개 문구 중 하나를 받아요.
- **하루 한 번** — 같은 날 다시 방문하면 받았던 문구를 그대로 보여드려요.
- **문구 복사** — 마음에 드는 한마디를 복사해서 간직하거나 나눌 수 있어요.

모바일과 데스크톱을 지원하며, 키보드로도 이용할 수 있습니다.

## 이용 방법

1. 오늘의 기분을 골라요. 고르지 않으면 ‘평범’으로 시작해요.
2. 원하는 메시지 유형을 선택해요.
3. **오늘의 한마디 뽑기**를 누르면 편지가 열려요.
4. 다음 날 새로운 한마디를 받아보세요.

| 메시지 유형 | 어떤 말을 전하나요? |
| --- | --- |
| 오늘의 운세 | 일상에서 만날 법한 작은 행운 |
| 오늘의 위로 | 친구처럼 편하게 건네는 위로 |
| 오늘의 팩폭 | 기분 상하지 않게 짚어주는 현실적인 한마디 |
| 오늘의 웃음 | 익숙한 일상에서 찾는 공감과 웃음 |

새 문구는 **한국 시간 자정**부터 받을 수 있습니다. 결과는 이용한 브라우저에 저장되며, 다른 기기로 옮겨지지 않습니다. 브라우저 저장 데이터를 지우면 결과도 초기화됩니다.

## 기술 스택

Next.js App Router · React · TypeScript · Tailwind CSS

사전 작성된 문구를 브라우저에서 선택하고 localStorage에 저장합니다. 별도의 서버 API나 데이터베이스 없이 정적 사이트로 동작합니다.

## 로컬 실행

Node.js 22.18 이상이 필요합니다. 환경변수나 API 키 설정은 필요하지 않습니다.

```sh
npm ci
npm run dev
```

브라우저에서 `http://localhost:3000`에 접속하세요.

```sh
npm test            # 테스트
npm run typecheck   # 타입 검사
npm run build       # 정적 빌드 → out/
```
