# 로드맵

## Phase 1 — 사전 작성 문구 MVP

- 브랜드·디자인, 기분 5개와 유형 4개 선택
- 조합별 10개씩 200개 문구와 무작위 선택
- 한국 시간 일일 결과, localStorage 복원과 오류 처리
- 결과 복사, 반응형, 접근성, 모션 감소
- 핵심 테스트와 정적 내보내기, 사용자 수락 후 Vercel 배포

출시 후에는 이용자 피드백으로 표현 품질과 조합별 다양성을 개선한다.

## Phase 2 — 친구에게 한마디 보내기

공유 UX와 개인정보·저장 범위를 먼저 설계하고 필요한 기능만 도입한다.

## Phase 3 — 선택적인 문구 공급 확장

수요와 운영비를 검토한 후 Gemini API 또는 DB 기반 공급 방식을 결정한다. AI_PROMPTS.md 초안을 검토하고 필요한 서버 검증과 안전장치를 구현한다. 현재 MVP에는 어느 쪽도 포함하지 않는다.

## Phase 4 — 분석 및 광고 검토

개인정보 처리와 호스팅 상업 이용 조건을 확인한 뒤 분석·수익화를 검토한다. 무료 플랜에서 상업 운영이 가능하다고 가정하지 않는다. 현재 UI에는 광고 영역을 두지 않는다.
