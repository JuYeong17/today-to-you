# AI 프롬프트 — 향후 연동 초안

**현재 미사용.** 1차 MVP의 런타임 문구는 `src/features/daily-message/messages.ts`에 사전 작성되어 있다. 이 문서는 코드에서 불러오지 않으며 Gemini API, SDK와 키는 존재하지 않는다.

## 공통 정책 초안

자연스러운 한국어 한 문장, 공백 포함 45자 이내, 친근하고 담백한 반말. 제목·설명·이모지·해시태그·따옴표를 제외한다. 감정 평가, 모욕, 죄책감, 불안, 공포, 열등감, 자기혐오, 건강·사고·죽음 예언과 근거 없는 확신을 금한다. 기존 저작물을 복사하지 않는다.

## 유형 정책 초안

- FORTUNE: 재미있는 가능성만 제시하며 미래를 단정하지 않는다.
- COMFORT: 감정을 존중하고 억지 긍정과 감정 과잉을 피한다.
- REAL_TALK: 인격과 능력을 평가하지 않고 작은 행동을 제안한다.
- HUMOR: 일상 공감형 농담을 사용하고 집단이나 개인을 조롱하지 않는다.

## 기분 정책 초안

- HAPPY: 좋은 기분을 존중하며 과도한 의욕을 요구하지 않는다.
- NORMAL: 소소한 재미와 부담 없는 제안을 한다.
- TIRED: 휴식과 낮은 부담을 우선한다.
- SAD: 감정을 바꾸도록 압박하지 않고 조심스럽게 표현한다.
- EXCITED: 기대를 존중하며 결과를 보장하지 않는다.

기분과 유형이 충돌하면 감정적 안전을 우선한다. SAD·TIRED의 팩폭은 공격적이지 않아야 한다.

## 향후 구현 시 검토할 사항

공통·기분·유형 프롬프트를 코드에서 분리하고, 구조화된 JSON 응답을 서버에서 스키마·길이·안전성 기준으로 검증한다. 실패 시 검수 문구를 제공한다. 프롬프트만으로 안전성을 보장하지 않는다. 전체 조합의 반복 표본, 경계 입력, API 오류·검증 실패 테스트를 계획한다. 실제 도입 전에 모델과 공식 API 문서를 사용자 수락 하에 확인한다.
